- Four fixed-step experiments on Earth, Moon, Mars; measured data and aligned comparison.
- Local validated recipe recovery; cloud and AI adapters fail clearly when credentials are absent.
- Typecheck, physics/domain/server tests, production build, browser journey and responsive review.

3. Integrate, review races and boundaries, run local gates and fix failures.
